ATURAN & CARA MAIN

Baca dulu sebelum main. Aturan ini menjaga server tetap nyaman buat semua orang, dan langkah di bawah membantu kamu bergabung dalam hitungan menit.

Cara Bergabung

Ikuti langkah berikut dari awal buka Minecraft sampai masuk ke dunia server.

  1. 1

    Buka Minecraft Java Edition

    Pastikan versi game kamu 1.20.x agar kompatibel dengan server.

  2. 2

    Masuk ke menu Multiplayer

    Klik Add Server lalu isi nama server sesuka kamu, misalnya "Economy Dewa SMP".

  3. 3

    Masukkan alamat dan port

    Isi Server Address dengan play.economydewa.my.id:25502, lalu simpan.

  4. 4

    Klik Join Server

    Tunggu proses koneksi selesai dan kamu akan masuk ke spawn area.

  5. 5

    Ikuti tutorial di spawn

    Baca papan panduan di spawn untuk mulai memilih job dan klaim lahan pertamamu.

Aturan Server

Pelanggaran terhadap aturan ini bisa berujung teguran, mute, hingga banned tergantung tingkat keparahannya.

  1. Dilarang griefing dan mencuri

    Merusak atau mengambil barang di klaim orang lain tanpa izin akan langsung ditindak.

  2. Dilarang menggunakan cheat atau mod ilegal

    X-ray, hack client, dan auto-clicker untuk PvP dilarang keras dan berujung banned permanen.

  3. Jaga sopan santun di chat

    Tidak ada toleransi untuk SARA, ujaran kebencian, atau spam berlebihan.

  4. Dilarang scam antar pemain

    Transaksi jual beli harus jujur; penipuan trading dapat dilaporkan ke admin dengan bukti.

  5. Satu akun per pemain

    Multi-akun untuk memanipulasi ekonomi atau voting tidak diperbolehkan.

  6. Ikuti instruksi staff

    Keputusan admin dan moderator saat menangani konflik bersifat final selama masih wajar.
